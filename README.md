# Password Strength & Entropy Evaluator

A simple Python tool to test how secure your passwords are using math (bits of entropy) and security best practices.

---

## Features

- **Entropy Check:** Measures password randomness in bits.
- **Leak Warning:** Flags common weak passwords (like `123456` or `password`).
- **Complexity Check:** Checks for uppercase, lowercase, numbers, and symbols.
- **Smart Feedback:** Gives quick tips to make your password stronger.
